# CERTIS Public Website — Live Board Concept

Locked concept implementation:

- CERTIS wordmark is the living visual board.
- Digital products, Bitcoin, XRP, market signals, and evidence flow through the name.
- Enter CERTIS transitions into the Live Board instead of a disconnected marketing surface.
- Public customer experience and founder/admin plane remain separate.
- No direct backend or SQLite access is embedded in this shell.
- Provider activation and financial authority are not changed.

This is a static deployment prototype intended for preview/hosting integration.
